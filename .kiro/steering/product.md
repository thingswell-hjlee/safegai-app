# Product — SafeGAI 관리자 모바일앱 + AWS 백엔드 (트랙 B)

마포구립장애인직업재활센터의 스마트안전 시스템에서, 현장 게이트웨이(트랙 A)가 올려보내는
안전 이벤트를 AWS에서 수신·보관하고, 관리자 모바일앱으로 푸시·조회·조치를 제공한다.

## 존재 이유

- 관리자가 현장에 없어도 위험을 10초 안에 알고, 확인·조치 이력이 남는다.
- 현장 경보(경광등·부저)는 게이트웨이 소유 — 이 시스템이 죽어도 현장 안전은 무영향.
- 앱은 감시·평가 도구가 아니라 관리자의 대응 도구다.

## 사용자와 역할 (Cognito 그룹)

- admin(시설 관리자): 조치 주체. 담당 지정 가능.
- teacher(직업훈련교사): 확인(ack) 가능, 환경·재실 조회.
- operator(운영 책임자): 요약 조회, 에스컬레이션 최종 수신.
- maintainer(유지보수): FAULT 이벤트 전담.

## 범위 (1차 PoC)

- P0: 이벤트 수신(멱등)→보관(90일 TTL)→푸시(등급별)→앱 조회→조치 3단계→에스컬레이션 1/3/5분.
- 화면 M1~M8 (docs/spec-b.md 6장 바인딩표).
- Android 우선. iPhone은 다음 단계(토큰 계층만 변경).
- 제외: 통계 고도화, 다시설 관제, 얼굴인식·개인식별(영구 제외).

## 절대 지켜야 할 제품 원칙

1. 이벤트의 유일한 원천은 게이트웨이. 서버·앱이 안전 이벤트를 만들어내지 않는다(GATEWAY_OFFLINE FAULT 제외).
2. 푸시는 비보장 전제 — 안전망은 서버 에스컬레이션(docs/push-policy.md).
3. 네트워크 모드 선택 UI 금지 — 자동 판정만(docs/network-modes.md).
4. 조치 상태는 역행 금지, 모든 전이에 누가·언제 기록.
5. 개인정보 최소: 이름·역할만. 영상·개인식별 데이터 없음.
